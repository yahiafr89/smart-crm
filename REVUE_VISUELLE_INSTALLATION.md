# Smart CRM — Revue visuelle et correctif CSS

## Base
Le fichier CSS complet inclus reprend le CSS du précédent lot
SmartCRM_HARMONISATION_VISUELLE_FINALE.zip, avec un ajout de règles ciblées.

## Vérifications réalisées
- Inspection des sources HTML/CSS fournies dans le projet.
- Vérification des classes présentes dans les pages publiques et CRM.
- Vérification de l'intégrité de l'archive et du contenu CSS.
- Aucune modification de JavaScript, Supabase, n8n ou login.html.

## Limites
La recette visuelle sur le site déployé et les tests interactifs
authentifiés n'ont pas pu être exécutés. Les corrections restent à
vérifier dans Safari sur MacBook, tablette et mobile.

## Installation
1. Sauvegarder CSS/style.css.
2. Extraire ce ZIP à la racine du projet en conservant CSS/.
3. Remplacer CSS/style.css UNIQUEMENT si le CSS installé provient
   du précédent lot d'harmonisation. Sinon fusionner les ajouts en fin
   de fichier pour préserver les modifications plus récentes.
4. Rafraîchir Safari avec Cmd + Option + R.
5. Contrôler Accueil, À propos, Services, Contact, Dashboard,
   Prospects, fiche prospect, Commerciaux et Administration.

## Synchronisation
Mettre à jour CSS/style.css dans le projet ChatGPT et publier sur GitHub
après vérification locale.
